In an attempt to learn and maintain web infrastructures, I have spent a lot of time to familiarize myself with these tools so I can streamline my documentation:

- [Obsidian](https://obsidian.md) - An amazing note taking app for writing down thoughts *(and also writing some posts!)*
- [Git](https://git-scm.com) - A source control system that I primarily use to sync changes across my devices

**Honorable mention:** I use [SimpleCSS](https://simplecss.org) for my portfolio's CSS theme
